# 100 Days of Python Portfolio

Welcome to my Python programming portfolio! This repository serves as a clean, structured showcase of my daily progress, programming logic, and core concepts built during the 100 Days of Code challenge. 

Each project is designed to tackle specific foundational milestones in software development.

---

## 📁 Project Showcase

### 01. Band Name Generator
* *File:* 01_Band Name Generator Project.py
* *What it does:* An interactive program that captures user text inputs (like a city and a pet's name) and combines them into a creative band name.
* *Core Concepts:* Managing terminal output with print(), pausing execution for user data with input(), string concatenation (+), and basic variable storage.

### 02. Tip Calculator
* *File:* 02_Tip Calculator Project.py
* *What it does:* A practical financial script that takes a total bill, applies a custom tip percentage, and splits the final balance evenly among a group of people.
* *Core Concepts:* Data type manipulation, explicit type casting (float(), int()), arithmetic operators, mathematical rounding, and dynamic output formatting using F-strings.

### 03. Treasure Island Game
* *File:* 03_Treasure Island Game Project.py
* *What it does:* A choice-based narrative adventure game where player decisions lead along branching pathways to either hidden treasure or unique game-over screens.
* *Core Concepts:* Control flow structure using if, elif, and else, nested conditional pathways, logical operations, and defensive text standardization using .lower().

### 04. Rock, Paper, Scissors
* *File:* 04_Rock Paper Scissors Game Project.py (or your exact file name)
* *What it does:* A digital version of the classic game allowing a user to compete head-to-head against an automated computer opponent, complete with custom ASCII art layouts.
* *Core Concepts:* Utilizing the random module for unpredictable behavior, working with Python lists (arrays), index matching, and validating input boundaries to prevent runtime errors.

### 05. PyPassword Generator
* *File:* 05_Password Generator Project.py (or your exact file name)
* *What it does:* A security tool that generates highly secure, unpredictable passwords based on user-defined preferences for letter, number, and special character counts.
* *Core Concepts:* Definite loops using for, sequence generation via random.choice(), item list aggregation, and list randomization using random.shuffle().
